캐릭터 동기화(idle, 달리기, 점프, 회전)
총 주웠을때 상대방 화면에 보임.
총을 클라에서 말고 서버에서 랜덤한 위치에 생성(지금은 지정한 좌표에 생성).

로그인ui 적용 -> 이것때문에 기존에 했던 캐릭터 동기화와 총 주웠을 때를 사용하지 못하게 되어서 다시 적용. 근데 어차피 나중에 2라운드 맵 이동을 해야했기 때문에 미리 발견해서 다행.

과거의 방식 : 상대방 캐릭터의 위치를 맞출 때 setactorlocation(강제 순간이동)이나 vinterpto(부드러운 순간이동)를 사용
문제 : 언리얼의 애니메이션은 물리적인 속도를 보고 뛰는지 걷는지 판단.

현재의 방식 : addmovementinput을 사용해 상대방 캐릭터가 스스로 앞으로 향해 뛰게 만듦.
데드 로코닝 기법 : 목표 위치에 도착했는데 다음 패킷이 안와도 멈칫거리지 않고 원래 뛰던 방향으로 계속 뛰게 놔두는 방식.

과거의 방식 : 언리얼에 총을 직접 드래그해서 배치.
문제 : 서버는 맵에 총이 있는 지 모름. 하나만 있을때는 괜찮은데 아이템이 여러가지 일때는 어떤 아이템을 주웠는지 모르는 문제가 발생.

현재의 방식 : 맵에 있던 총을 다 지우고, 게임 시작 시 서버가 특정 좌표에 아이템 소환.
아이템에 고유 id를 발급하는 방식.
